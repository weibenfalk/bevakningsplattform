# Arbetsprov: bevakningsplattform

Börja med att läsa `Arbetsprov-bevakningsplattform.pdf`. Den innehåller uppdraget och specifikationen.

| Sökväg | Innehåll |
|---|---|
| `Arbetsprov-bevakningsplattform.pdf` | Uppdrag och specifikation |
| `src/`, `test/` | Påbörjad kodbas från en tidigare utvecklare (NestJS, Knex, PostgreSQL) |
| `data/` | Påhittad testdata: entitetsregister, källor, användare, profiler och råtexter för två körningar |
| `LICENSE` | 0BSD. Behåll filen i ditt repo |

Startkoden är något förkortad. Moduluppsättning, autentisering, CSV-hjälpare och testhjälpare saknas, liksom migrationer och `package.json`. Det som finns är det som levererades inom ramen för pipelinen, åtkomsten och utskicket.

Räkna med att klockan är 2026-10-01 07:00 svensk tid när pipelinen körs första gången, och 2026-10-03 07:00 vid körningen med `raw_items_dag2.json`.
